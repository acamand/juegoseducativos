# 📐 ¡A medir ángulos!

Aplicación web educativa para alumnos de **5º de Primaria** sobre ángulos y
el sistema sexagesimal: grados, minutos y segundos.

## 🚀 Cómo usar

No necesita instalación ni servidor. Solo abre `index.html` en cualquier
navegador moderno.

```bash
# Opcional: servirlo con un servidor local
python3 -m http.server 8000
# Y abre http://localhost:8000/angulos/
```

## 🎮 Actividades incluidas

1. **📖 Repaso** — Tipos de ángulos y tabla de equivalencias (°, ', '').
2. **📐 Clasifica ángulos** — Identifica si un ángulo dibujado es agudo, recto, obtuso, llano o completo.
3. **🔁 Conversiones** — Practica el paso entre grados, minutos y segundos.
4. **➕ Suma y resta** — Opera con medidas de ángulos en formato sexagesimal, con "llevadas".
5. **🎲 Mezcla** — Todas las actividades mezcladas al azar.

## ⭐ Características

- Dibujo dinámico de ángulos con SVG.
- Sistema de puntuación con aciertos y fallos (se guarda en el navegador).
- Explicación pedagógica tras cada respuesta.
- Diseño adaptado a móvil y tableta.
- Sin dependencias externas: HTML + CSS + JavaScript puros.
